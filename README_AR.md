# نظام كيان ERP - دليل التشغيل الكامل

## 🚀 نظرة عامة

**نظام كيان ERP** هو نظام شامل لإدارة الموارد يشمل:
- نقاط البيع (POS)
- إدارة المخزون
- إدارة العملاء والموردين
- الحسابات والقيود المحاسبية
- التقارير والتحليلات
- نظام متعدد الفروع
- نظام الاشتراكات

## 📦 التثبيت والإعداد

### الخطوة 1: تحميل الملفات
1. قم بتحميل المشروع كاملاً
2. فك ضغط الملف في مجلد على جهازك
3. افتح المجلد باستخدام محرر الأكواد

### الخطوة 2: تثبيت المكتبات
افتح Terminal/Command Prompt في مجلد المشروع واكتب:

```bash
npm install
```

انتظر حتى تكتمل عملية التثبيت (قد تستغرق عدة دقائق).

### الخطوة 3: إعداد قاعدة البيانات SQL Server

#### 1. إنشاء قاعدة البيانات
افتح **SQL Server Management Studio (SSMS)** ونفذ الملف:
```
DATABASE_SQL_SERVER/01_CREATE_TABLES.sql
```

هذا الملف سيقوم بـ:
- إنشاء قاعدة بيانات باسم `KayanERP`
- إنشاء جميع الجداول المطلوبة
- إنشاء الفهارس والعلاقات

#### 2. إنشاء الإجراءات المخزنة
نفذ الملف:
```
DATABASE_SQL_SERVER/02_STORED_PROCEDURES.sql
```

هذا الملف يحتوي على:
- إجراء تسجيل المستخدمين
- إجراء تسجيل الدخول
- إجراء إنشاء الفواتير
- إجراء تحديث المخزون
- إجراءات التقارير

### الخطوة 4: إعداد ملف الإعدادات

أنشئ ملف باسم `.env` في المجلد الرئيسي للمشروع واكتب فيه:

```env
# بيانات الاتصال بقاعدة البيانات
DB_SERVER=localhost
DB_PORT=1433
DB_NAME=KayanERP
DB_USER=sa
DB_PASSWORD=كلمة_المرور_الخاصة_بك

# إعدادات التطبيق
VITE_APP_NAME=KAYAN ERP
VITE_APP_VERSION=2.1.0

# إعدادات الأمان
JWT_SECRET=your-secret-key-here-change-this-in-production
SESSION_SECRET=your-session-secret-here
```

**هام جداً:**
- استبدل `كلمة_المرور_الخاصة_بك` بكلمة مرور SQL Server الحقيقية
- استبدل `localhost` باسم السيرفر إذا كان مختلفاً
- غيّر `JWT_SECRET` و `SESSION_SECRET` لقيم عشوائية آمنة

## 🔧 الإعدادات المتقدمة

### 1. تغيير المنفذ (Port)
في ملف `vite.config.ts`:
```typescript
export default defineConfig({
  server: {
    port: 3000, // غيّر الرقم حسب الحاجة
  }
})
```

### 2. إعداد اتصال قاعدة البيانات عن بُعد
في ملف `.env`:
```env
DB_SERVER=192.168.1.100  # IP السيرفر
DB_PORT=1433
DB_USER=your_username
DB_PASSWORD=your_password
```

### 3. تفعيل HTTPS
أضف في `vite.config.ts`:
```typescript
server: {
  https: true,
}
```

## 🐛 حل المشاكل الشائعة

### المشكلة 1: خطأ في الاتصال بقاعدة البيانات
**الحل:**
1. تأكد من تشغيل SQL Server
2. تحقق من بيانات الاتصال في `.env`
3. تأكد من تفعيل TCP/IP في SQL Server Configuration Manager

### المشكلة 2: الصفحة فارغة أو بيضاء
**الحل:**
1. افتح Console في المتصفح (F12)
2. ابحث عن الأخطاء
3. تأكد من تثبيت جميع المكتبات: `npm install`

### المشكلة 3: خطأ في البناء (Build Error)
**الحل:**
```bash
# احذف المجلدات المؤقتة
rm -rf node_modules
rm -rf dist

# أعد التثبيت
npm install
npm run build
```

### المشكلة 4: البطء في التحميل
**الحل:**
1. تأكد من وجود indexes في الجداول
2. قلل عدد البيانات المسترجعة
3. استخدم Pagination

## 🚀 النشر (Deployment)

### 1. بناء المشروع للإنتاج
```bash
npm run build
```

### 2. رفع الملفات
- انسخ مجلد `dist` إلى السيرفر
- تأكد من إعداد قاعدة البيانات

### 3. إعداد السيرفر
- استخدم **IIS** لـ Windows
- أو **Nginx** لـ Linux
- تأكد من تفعيل HTTPS

### 4. إعدادات DNS
- وجّه النطاق إلى IP السيرفر
- أضف SSL Certificate
